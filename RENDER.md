# Бесплатный запуск на Render без регистрации в MaxMind

Проект сам скачивает бесплатную **DB-IP Country Lite** на Render.
Аккаунт MaxMind, платная база, API-ключ и постоянный диск для этого не нужны.
База сохраняется во временной файловой системе и загружается снова при необходимости.
После перехода на новую месячную версию сервер обновляет её при следующем старте.

## Настройки формы Web Service

| Поле | Значение |
| --- | --- |
| Source | bekturlider-lab/vpn-atlas |
| Language | Node |
| Branch | main |
| Root Directory | оставить пустым |
| Build Command | npm ci |
| Start Command | npm start |
| Compute | Free ($0/month) |

В Environment Variables добавьте только:

```dotenv
NODE_ENV=production
GEOBLOCK_ENABLED=true
```

Не нажимайте Generate: здесь нужны буквальные значения production и true.
Дополнительные переменные для стандартной установки не требуются.
Если ранее указывали GEOIP_DB_PATH вручную и не загружали свою базу,
уберите эту переменную: по умолчанию используется data/dbip-country-lite.mmdb.
Не задавайте RENDER вручную: эту переменную выставляет платформа.

В Advanced можно указать Health Check Path: `/healthz`.
Этот маршрут отвечает только текстом `ok`, без контента сайта, IP или данных базы.

Нажмите Deploy Web Service. Первый запуск скачает базу стран. Дождитесь Live.
При сбое загрузки сервер не открывает сайт без проверки; подробности будут в логах.

## Проверка

- IP, который база относит к KG → HTTP 403.
- Известный IP другой страны → страница сайта.
- Отсутствующая/невалидная геолокация → HTTP 403.
- /healthz → только `ok`, независимо от страны, для проверки работоспособности.

Render автоматически обнаруживается через RENDER=true. Для публичных запросов
с приватного прокси Render используется CF-Connecting-IP, выставленный его
Cloudflare-периметром. Произвольный X-Forwarded-For не используется в этом режиме.
Если доверенный заголовок отсутствует или испорчен, страна считается неизвестной.
На другом хостинге этот адаптер включать нельзя: настройте TRUSTED_PROXIES
для конкретного прокси по README.

Правильность маршрута и фактическую блокировку нужно проверить на опубликованном
URL с подключениями из разных стран. Автоматические тесты проверяют код на фикстурах.

## Ограничения бесплатного режима

Free может засыпать после бездействия и запускаться дольше при следующем заходе.
Лимиты тарифа контролируются Render. Не подключайте платный план, если он не нужен.
Актуальные условия: https://render.com/docs/free

DB-IP Lite имеет неполную точность. Эта база определяет страны, не регионы или города.
Регионы в браузерном симуляторе остаются учебным примером. Для реальных региональных
правил нужна отдельная City-база. VPN меняет видимую страну и может обойти запрет KG.
