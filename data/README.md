# Бесплатная база стран

На Render сервер автоматически скачивает DB-IP Country Lite без регистрации и API-ключей.
База хранится в data/dbip-country-lite.mmdb. Платный постоянный диск не нужен:
после потери временных файлов база загружается при следующем старте.

Для ручной загрузки на своём компьютере:

```sh
npm run geoip:download
```

Для автоматической загрузки вне Render задайте GEOIP_AUTO_DOWNLOAD=true.
GEOIP_DB_PATH задаёт путь к файлу. При недоступной или невалидной базе
сервер не открывает сайт без проверки.

База обновляется ежемесячно. При следующем запуске в новом месяце загрузчик
проверяет новую версию; если она ещё не опубликована, пробует предыдущий месяц.
Постоянно работающий сервер нужно перезапустить для обновления данных.

Country-база не содержит регионов и городов. Для региональных правил подключите
совместимую City-базу отдельно, задайте её путь в GEOIP_DB_PATH и отключите
автозагрузку: GEOIP_AUTO_DOWNLOAD=false. Поддерживаются схемы с country.iso_code
и subdivisions[0].iso_code. Условия сторонней базы проверяйте у поставщика.

Источник: [IP Geolocation by DB-IP](https://db-ip.com).
Бесплатный выпуск: https://db-ip.com/db/download/ip-to-country-lite

База не модифицируется, только распаковывается; её файлы исключены из Git и архивов.
Ни один IP посетителя не передаётся в DB-IP: поиск производится локально.
