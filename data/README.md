# Подключение GeoIP-базы

В учебном режиме база не нужна. Для реальной проверки получите совместимую базу
GeoLite2 City или GeoIP2 City в бинарном формате .mmdb у MaxMind:
https://dev.maxmind.com/geoip/geolite2-free-geolocation-data/

1. Создайте аккаунт MaxMind, ознакомьтесь с действующими условиями и требованиями атрибуции.
2. Скачайте City-базу, распакуйте архив и поместите файл как `data/GeoLite2-City.mmdb`.
   Для другого имени измените GEOIP_DB_PATH в .env. Country-база поддерживает страны,
   но не содержит регионов; для региональных правил используйте City-базу.
3. Укажите `GEOBLOCK_ENABLED=true` в .env и перезапустите сервер.
4. Обновляйте базу согласно условиям поставщика. После замены файла перезапустите сервер.
5. Если применяемая лицензия требует атрибуции, разместите её для своей установки
   в соответствии с актуальными условиями MaxMind.

База не включена в проект и не публикуется. Лицензия программы не даёт права
распространять данные стороннего поставщика. Ключи скачивания не сохраняйте
в public/, Git или публичных файлах.

IP-геолокация приблизительна и не определяет физический адрес человека:
https://support.maxmind.com/knowledge-base/articles/maxmind-geolocation-accuracy

Региональное правило использует `country.iso_code` и `subdivisions[0].iso_code`.
Если регион отсутствует и есть правила для регионов этой страны, действует unknownAction.
Примеры: DE-BE (Берлин), DE-BY (Бавария), US-CA (Калифорния), US-NY (Нью-Йорк).
